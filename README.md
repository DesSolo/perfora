# Perfora

Веб-редактор вставок для блокнотов на кольцах и дисках: страницы любого размера, свободная раскладка картинок и текста, печать 1:1 в миллиметрах. Работает целиком в браузере, без бэкенда.

Опубликован на GitHub Pages: https://dessolo.github.io/perfora/ (собирается из `master` workflow `.github/workflows/pages.yml`).

## Запуск

```bash
npm install
npm run dev          # http://localhost:5173 (или `make run`: сам поставит зависимости)
npm run build        # статическая сборка в dist/ (base: './', можно открыть с любого пути)
npm test             # unit-тесты (Vitest)
npm run e2e          # e2e (Playwright), сам поднимает dev-сервер на :5174
```

Если браузеры Playwright не установлены (`npx playwright install chromium`), можно указать системный Chromium:

```bash
PW_CHROMIUM_PATH=/usr/bin/chromium-browser npm run e2e
```

## Стек и почему

- **TypeScript + Vite.**
- **React 19.** Выбран вместо Svelte из-за зрелой экосистемы и предсказуемости. Плавность при перетаскивании держится на неизменяемом состоянии (immer): у нетронутых блоков ссылки не меняются, и `memo` пропускает их перерисовку. Миниатюры обновляются через `useDeferredValue` и не тормозят холст.
- **zustand** для стора, **immer** для неизменяемых операций, **DOMPurify** для санитизации текста, **fflate** для zip (маленький, без зависимостей). IndexedDB используется напрямую, без обёрток.
- Рендер страницы через DOM в единицах `mm`. Масштаб холста задаётся `transform: scale`, поэтому та же разметка пойдёт на печать без пересчёта.
- Шрифты из `@fontsource` (PT Sans, PT Serif, Caveat, JetBrains Mono, все с кириллицей) попадают в сборку, CDN не нужен.

## Структура

```
src/
  core/        чистый TS без DOM: модель, операции, история, миграции, геометрия (покрыто тестами)
    geometry/  трансформации, переплёт (отверстия, поля, зеркалирование), привязка, развороты, импозиция
  data/        presets.json — встроенные пресеты привязки (данные, не код)
  assets/      импорт и уменьшение картинок, хранилище Blob на время сессии
  persist/     IndexedDB, zip, автосохранение и открытие проектов
  text/        санитизация HTML текстовых блоков
  store/       стор редактора: история, выделение, жесты, действия
  i18n/        словари RU/EN
  ui/          React-компоненты
e2e/           Playwright
```

## Готово (M1: ядро редактора)

- Проект и размер страницы: пресеты A4, A5, A6, B5, Letter, Half Letter, произвольный размер в мм, смена ориентации.
- Страницы: добавить, дублировать, удалить, переставить (перетаскиванием миниатюр или кнопками). Миниатюры рендерятся лениво.
- Картинки: кнопка, drag-and-drop на холст, вставка из буфера, несколько файлов за раз. При импорте картинка уменьшается до 150/200/300 dpi от наибольшего размера, в который она вписывается в поля страницы; уменьшение можно отключить. Режимы вписывания: вписать, заполнить, растянуть.
- Текст: редактирование прямо на странице (двойной клик или Enter), шрифт, размер в pt, жирный, курсив, подчёркивание, выравнивание, цвет, межстрочный интервал, маркированные и нумерованные списки. HTML санитизируется, вставка из буфера идёт как простой текст.
- Блоки: перемещение, изменение размера (у картинок пропорции сохраняются, Shift это отключает; у текста наоборот), поворот (Shift даёт шаг 15°), порядок слоёв, дублирование, удаление, блокировка, числовой ввод X/Y/W/H/угла.
- Undo/redo на 100 шагов. Жест перетаскивания записывается одним шагом, подряд идущие нажатия стрелок и ввод в поле сливаются.
- Клавиши: стрелки (1 мм, с Shift 10 мм), Delete/Backspace, Ctrl/Cmd+D, Ctrl/Cmd+Z, Ctrl/Cmd+Shift+Z (и Ctrl+Y). Работают в любой раскладке.
- Интерфейс на RU/EN, светлая и тёмная тема по системной настройке. Страница всегда белая.

## Готово (M2: привязка и печать)

- Поля: внутреннее, внешнее, верхнее, нижнее. Внутреннее всегда у переплёта и на чётных страницах переезжает на другую сторону.
- Переплёт: сторона (слева, справа, сверху), зеркалирование чётных страниц для двусторонней печати, число отверстий, диаметр, шаг, отступ от кромки до центра, центрирование или отсчёт от первого отверстия, зона запрета.
- Пресеты привязки лежат в `src/data/presets.json`. Пока там один тестовый A5 на 6 отверстий с пометкой «проверить». Свои пресеты сохраняются в браузере.
- Отверстия и зона запрета видны на холсте и миниатюрах. Блок, заходящий в зону, обводится красным, предупреждение появляется в инспекторе и значком «!» на миниатюре. Печать при этом не блокируется.
- Переключатели вида: поля, отверстия, зона запрета, сетка 5/10 мм, привязка.
- Режим разворота: страница 1 одна справа, дальше пары 2–3, 4–5. При верхнем переплёте страницы идут друг над другом.
- Привязка к краям и центру страницы, полям, краям и центрам других блоков, с направляющими. Работает при перемещении и при ресайзе неповёрнутого блока. Alt временно отключает.
- Печать: `@page { size: W×H mm; margin: 0 }`, страницы 1:1. Шрифты и картинки догружаются до открытия диалога. Ctrl/Cmd+P идёт тем же путём.
- Предпросмотр печати использует тот же компонент страницы, что и печать.
- Метки отверстий: не показывать, только на экране или печатать (окружность с перекрестием для перфоратора).
- Двусторонняя печать: если принтер переворачивает лист не по той кромке, по которой листают блокнот, оборотные страницы поворачиваются на 180°. Инспектор подсказывает, какой переворот нужен.

## Готово (M3: сохранение)

- Автосохранение в IndexedDB через 0,5 с после правки, не посреди перетаскивания. Немедленная запись при уходе со вкладки и по Ctrl/Cmd+S. Статус («Сохранение…», «Сохранено в браузере», «Не сохранено») виден рядом с названием. При ошибке записи (например, нет места) появляется сообщение с советом экспортировать проект.
- При запуске открывается последний открытый проект (если его нет, то последний изменённый). Ожидание IndexedDB ограничено 3 с, опоздавший ответ отбрасывается.
- Экспорт в `.zip`: `project.json` и `assets/<id>.<ext>`. Картинки кладутся без пересжатия. Имя файла берётся из названия проекта.
- Импорт `.zip` кнопкой, перетаскиванием на холст или через диалог «Проекты». Читается и архив, пересобранный из распакованной папки (всё внутри одного каталога). Импорт всегда создаёт новый проект и не перезаписывает существующий.
- Миграции схемы: цепочка шагов `n → n+1` в `core/migrate.ts`. Затем проект собирается заново из известных полей: недостающее берётся из значений по умолчанию, битые блоки отбрасываются, повторяющиеся id заменяются. Что исправлено и сколько картинок потеряно, сообщается после открытия. Проект из более новой версии не открывается, выводится понятное сообщение.
- Диалог «Проекты» (кнопка с папкой, Ctrl/Cmd+O): новый проект, открыть `.zip`, экспорт, список недавних с датой, числом страниц и размером, удаление из браузера с подтверждением.
- Браузер просят не вытеснять данные (`navigator.storage.persist()`).

## Готово (M4: импозиция и калибровка)

- Раскладка на лист: A4, Letter или произвольный, колонки × ряды, зазор. Кнопка «Сколько влезет» подбирает наибольшую сетку. Лист сам становится альбомным, если сетка влезает только так. Если сетка не помещается, появляется предупреждение.
- Дуплекс при раскладке: на лицевой стороне идут лица листков, оборот каждого печатается в зеркальной ячейке с учётом того, по какой кромке принтер переворачивает лист. Если эта кромка не совпадает с кромкой переплёта, обороты повёрнуты на 180°. Подсказка о нужном перевороте считается по листу, а не по странице.
- Метки реза вокруг сетки на продолжениях линий реза (отступ 2 мм, длина 5 мм), только на лицевой стороне. Внутрь сетки не заходят, поэтому работают и при нулевом зазоре. Если до края листа нет места, инспектор об этом пишет.
- Ручной дуплекс: печать всех сторон, только лицевых или только оборотных, обратный порядок. «Только оборотные» добавляет пустой оборот для последнего листа, чтобы стопка не сбилась.
- Калибровка принтера: сдвиг лицевой и оборотной стороны по X/Y. Диалог «Калибровка…» печатает тестовый лист (линии в 10 мм от левого и верхнего края, перекрестие в центре для проверки на просвет, отрезок 100 мм для проверки масштаба) и считает сдвиг из измеренных расстояний.
- Предпросмотр показывает листы так, как они уйдут на принтер, с подписью «Лист N, лицо/оборот» и номерами страниц.

## Допущения и отступления от ТЗ

- В `Project` добавлено поле `assets: Record<id, AssetMeta>` с метаданными картинок (имя, mime, размер в пикселях). Сами Blob хранятся отдельно. Без этого поля проект нельзя собрать в zip и проверить на целостность.
- В текстовом блоке «Жирный» и «Курсив» работают двояко. В режиме редактирования они применяются к выделенному фрагменту (теги `<b>` и `<i>`), вне его меняют `style.weight` и `style.italic` всего блока. Подчёркивание и списки доступны только в режиме редактирования.
- Разрешённые теги текста: `p, div, br, b, strong, i, em, u, s, ul, ol, li`, атрибуты запрещены.
- Текст, не помещающийся в блок, обрезается по его границе, чтобы на печати было ровно то же, что на экране.
- Поля по умолчанию: внутреннее 15 мм, остальные 8 мм. Размер страницы по умолчанию A5.
- Id проекта в IndexedDB хранится в сторе, а не в `Project`: модель следует ТЗ, а при импорте zip всё равно нужен новый id.
- История undo не сохраняется: после перезагрузки она пустая.
- Пустой новый проект не записывается, пока в нём ничего не изменили, иначе список недавних засоряется.
- При сохранении и экспорте из `assets` выбрасываются метаданные картинок, которых нет ни на одной странице.
- Схема 1 первая, поэтому шагов миграции пока нет. Механизм проверен тестами на подставных шагах.
- Две вкладки с одним проектом не синхронизируются: в базе остаётся та версия, которая записана последней.
- Координаты на чётной странице — это оборот листа так, как его видит читатель после переворота вокруг кромки переплёта. Боковой переплёт зеркалится как левый ↔ правый, верхний как верх ↔ низ, то есть на обороте отверстия оказываются у нижней кромки, как в календаре.
- Поля при верхнем переплёте: `inner` у кромки переплёта, `bottom` у противоположной кромки, `outer` слева и справа, `top` не используется.
- `holeMarks: 'off'` скрывает отверстия и на экране. Переключатель «Отверстия» на панели только временно прячет их с холста.
- Переплёт по умолчанию включён, параметры взяты из тестового пресета.
- Пользовательские пресеты и настройки вида хранятся в `localStorage`. Если он недоступен, они просто не переживают перезагрузку.
- Модель отверстий: равный шаг (`count` × `pitch`). Схемы с группами (например, 3 + 3 с промежутком) пока не выражаются, нужно расширение модели.
- Лист импозиции ориентируется автоматически (в модели ориентации нет): книжно, если сетка влезает, иначе альбомно. Произвольный лист тоже нормализуется. Сетка всегда центрирована, поэтому лицевая и оборотная ячейки совпадают при перевороте.
- Импозиция без зеркалирования (`mirror: 'none'`) считается односторонней: страницы идут подряд, оборотов нет.
- Метки реза без импозиции не печатаются: на листе размером со страницу для них нет места. Для одной страницы с метками нужна сетка 1×1 на листе крупнее.
- Сдвиг калибровки задаётся в системе координат печатаемой стороны (как она выходит из PDF), + вправо и вниз. Применяется ко всей стороне листа вместе с метками. Тестовый лист печатается без сдвига.
- Выбор сторон и обратный порядок не сохраняются в проекте: это настройка одного задания печати, после перезагрузки снова «Все».
- Печать проверена в headless Chromium: размер страницы PDF A5 = 420 × 594,96 pt, отклонение от номинала ≤ 0,17 мм. На реальном принтере с линейкой ещё не проверялось.
